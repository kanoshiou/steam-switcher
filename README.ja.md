# Steam Switcher

[English](README.md) | [简体中文](README.zh-CN.md) | [繁體中文](README.zh-TW.md) | 日本語 | [한국어](README.ko.md)

Windows 向けの Steam アカウント高速切り替えツール。操作イメージは Nintendo Switch のマルチユーザー選択画面です。この PC に記憶された Steam アカウントがトレイメニューに直接一覧表示され、クリックするだけで Steam が終了 → アカウントを切り替え → 目標のアカウントでログイン済みの状態で再起動します。パスワードの再入力も、ログイン画面で止まることもありません。

## 主な機能

- **ワンクリックでアカウント切り替え** —— Steam を終了 → ローカルのログイン設定を書き換え → 目標アカウントとしてサイレントに再ログイン。
- **トレイ最優先** —— トレイアイコンを右クリックするだけで、この PC の全 Steam アカウントを表示し、即座に切り替え。
- **設定ウィンドウ**(gpui-kit)—— アカウント管理、インストール済みゲーム一覧、テーマ/言語オプション、Steam のパスと起動引数。
- **アカウントを指定してゲーム起動** —— ゲームを左クリック:現在のアカウントでそのまま起動。右クリック:アカウントを選択してから起動(切り替え後にゲームが開始)。
- **デフォルトで安全** —— ゲームの実行中は Steam を終了する前に確認ダイアログを表示。書き込みのたびに `loginusers.vdf` をバックアップ(`loginusers.vdf.bak-YYYYMMDD-HHMMSS`、最新 3 世代を保持)。
- **多言語 UI** —— 日本語、简体中文、繁體中文、English、한국어。
- **細部の作り込み** —— ダーク/ライト/システム追従テーマ、スタートアップ起動、閉じてもトレイに最小化、単一インスタンス動作、すべての操作にトースト通知。

## 切り替えの仕組み

Steam のサイレント自動ログインは 2 か所で決まります。切り替え時には必ず両方を書き込みます。

1. **Steam を終了**(まずは正常終了を試行。ゲームが実行中の場合は先に確認)。
2. **`config/loginusers.vdf` を書き換え** —— 対象アカウントを `MostRecent=1` / `RememberPassword=1` に、他のアカウントを `MostRecent=0` に設定。ログイン画面で最初に選ばれるアカウントを決定します。
3. **レジストリに書き込み** `HKCU\Software\Valve\Steam` —— `AutoLoginUser`(サイレントログインするアカウント)と `RememberPassword=1`。
4. **Steam を再起動**(必要に応じて追加の起動引数を付けて)。

## ダウンロード

[Releases](../../releases) から zip をダウンロードできます。タグごとに 2 種類の Windows 実行ファイル(`x86_64-pc-windows-msvc`)をビルドします。

| バリアント | 内容 |
|---|---|
| `gui` | トレイアイコン + フル設定ウィンドウ(既定ビルド) |
| `tray` | トレイ専用。軽量で GUI 依存なし |

各 zip には `.sha256` チェックサムファイルが付属します。

> **対応プラットフォーム:** Windows 10/11 を最優先。macOS/Linux は計画中で、まだパッケージ化されていません。

## ソースからビルド

Rust 1.95+(stable)が必要です。

```sh
# GUI ビルド(トレイ + 設定ウィンドウ)
cargo build --release

# トレイ専用ビルド(gpui に依存しない)
cargo build --release --no-default-features
```

## 使い方のヒント

- **アカウントは自動検出** —— アカウント一覧は Steam 本体の `loginusers.vdf` から取得します。「パスワードを記憶する」にチェックして一度ログインすれば、そのアカウントが表示されます。
- **アカウントの削除** —— 設定ウィンドウでの削除はローカルのログイン情報のみを消します。ゲームの所有権やクラウドセーブには影響しません。
- **設定ファイル** の場所:`%APPDATA%\steam-switcher\config.json`。
- **ヒント:** 「設定 → 起動引数」に `-silent`(例:`-silent -no-browser`)を追加すると、ポップアップなしの高速切り替えになります。
